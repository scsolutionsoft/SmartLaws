# วันนัดอ่านคำพิพากษาและสำรองคดีก่อนลบ

หน้าแก้ไขข้อมูลคดีมีวันนัดอ่านคำพิพากษาแยกศาลชั้นต้น ศาลอุทธรณ์ ศาลฎีกา พร้อมรายการไฟล์ในสำนวน เพิ่มนัดแล้วใช้หน้ารายละเอียดนัดเชื่อมไฟล์เดิมหรืออัปโหลดไฟล์ใหม่ได้ คำพิพากษา PDF ใช้คลังเดิมและระบุเลขคดีดำ/แดง วันที่คำพิพากษา ชั้นศาล แยกจากวันนัดอ่าน

การดาวน์โหลด ZIP ทำได้จากรายการคดีหรือหน้าแก้ไขคดีโดยไม่ต้องลบ

ขั้นตอนลบ:
1. ยืนยันครั้งที่หนึ่ง ระบบรับ ZIP จนครบและสั่งเบราว์เซอร์ดาวน์โหลดอัตโนมัติ
2. ตรวจสอบไฟล์ในเครื่อง ติ๊กว่าได้รับและตรวจสอบ ZIP แล้ว พิมพ์ “ลบคดี” และยืนยันครั้งที่สอง

หากสร้าง ZIP ไม่สำเร็จ ผู้ใช้ยกเลิก หรือข้อมูลคดีเปลี่ยนหลังสำรอง จะไม่ลบข้อมูล โทเคนสำรองผูกกับคดีและบัญชี มีอายุ 30 นาที ใช้ได้เมื่อข้อมูลตรงกับ ZIP เท่านั้น เครดิตไม่เปลี่ยน

ZIP มี case-data.json (ข้อมูลคดี คู่ความ เอกสารรวมภาพลายเซ็น ไฟล์ วันนัด ขั้นตอนคดี และการเชื่อมไฟล์), files/ (ไฟล์อัปโหลดต้นฉบับ), documents/ (เอกสารสตูดิโอเป็น DOCX), links/ (ที่อยู่ไฟล์ภายนอก) และ README.txt ชื่อไฟล์ใช้รหัสซึ่งเทียบชื่อจริงได้ใน JSON ไม่ดาวน์โหลดเนื้อหาลิงก์ภายนอกอัตโนมัติ

เว็บตรวจยืนยันการเขียนลงดิสก์ไม่ได้ จึงต้องให้ผู้ใช้ตรวจ ZIP ก่อนยืนยันครั้งที่สอง ไม่มีการอ้างว่าดาวน์โหลดลงเครื่องสำเร็จโดยอัตโนมัติ

API: GET /api/cases/{id}/hearings, GET /api/cases/{id}/backup, DELETE /api/cases/{id} รับ JSON backupToken, confirmed, confirmation โดยใช้สิทธิ์เจ้าของคดีเดิม
