# เอกสารลูกความ เอกสารส่วนตัว และรายงานสรุป

- เอกสารลูกความ: เลือกคดี เลือกลูกความหรือเพิ่มคู่ความที่เป็นลูกความ แล้วเลือกสำเนาบัตรประชาชน ทะเบียนบ้าน หรือเอกสารอื่น รองรับ PDF/PNG/JPG ไม่เกิน 1 GB ตรวจประเภทไฟล์บนเซิร์ฟเวอร์และสตรีมลงดิสก์ส่วนตัว
- เอกสารส่วนตัวทนาย: บัตรใบอนุญาตทนายและเอกสารอื่นแยกตามบัญชีทนาย เจ้าของบัญชีเท่านั้นที่อ่าน/ลบได้ เสมียนและแอดมินเข้าถึงไม่ได้ ไม่แนบเข้าคดีโดยอัตโนมัติ
- ต้องสำรอง `App_Data/Uploads` ควบคู่กับฐานข้อมูล เพื่อให้เอกสารและไฟล์แนบยังเปิดได้เมื่อกู้คืนระบบ
- วิซาร์ดอัปโหลดมี 3 ขั้นตอน: เจ้าของ → ไฟล์ → ตรวจสอบ สามารถย้อนกลับโดยเก็บไฟล์ที่เลือกไว้
- เอกสารลูกความใช้ไฟล์จริงในคลังสำนวนเดิม เชื่อม CaseId/PartyId/FileId ใน SL_ClientDocuments และรวมใน ZIP สำรองคดี การลบคดีจะลบเอกสารลูกความตามคดี แต่เอกสารส่วนตัวใน SL_PersonalDocuments ยังคงอยู่
- เมนูเริ่มงานแบบวิซาร์ดช่วยเลือกงานเปิดคดี จัดเก็บเอกสาร วันนัด แบบพิมพ์ คลังไฟล์ รายงาน สำรองข้อมูล และติดต่อผู้ดูแล โดยใช้สิทธิ์เดิม
- รายงานสรุปคดี เอกสาร และวันนัด: เลือกทุกคดีที่มีสิทธิ์หรือรายคดี ดูรายการไฟล์ เอกสารสตูดิโอ นัดหมาย และสำเนาประจำตัวที่ยังไม่มี ส่งออก CSV สรุปหรือพิมพ์รายละเอียดเป็น PDF ผ่านเบราว์เซอร์
- จำนวนไฟล์และเอกสารสตูดิโอแสดงแยกกัน เพราะเอกสารสตูดิโออาจเชื่อมอยู่ในคลังด้วย จำนวนวันนัดในปฏิทินแสดงแยกจากวันนัดเก่าของสำนวน ไม่มีการรับรองความถูกต้องของเอกสารเพียงเพราะอัปโหลดครบ

API: /api/client-records, /api/client-records/{caseId}, /api/personal-documents, /api/personal-documents/{id}/content, /api/work-summary?caseId=...

เอกสารลูกความใช้สิทธิ์ทนายเจ้าของคดีและเสมียนที่ได้รับมอบหมาย รายงานรายละเอียดใหม่นี้ใช้สิทธิ์สำนวนเดิม แอดมินยังใช้รายงานทะเบียนสำนวนเดิม ไม่มีสิทธิ์เปิดเอกสารส่วนตัว
