# ทนายในสำนักงานและการมอบหมายคดี

ระบบสร้างตาราง `SL_LawOfficeMembers` และ `SL_OfficeCaseAssignments` แบบ idempotent ระหว่างเริ่มแอปผ่าน `OfficeTeam.InitializeAsync` จึงอัปเดตฐานข้อมูล SQL Server เดิมโดยไม่ย้ายหรือลบข้อมูลคดีเดิม

บัญชีทนายที่มีอยู่ทำหน้าที่เจ้าของสำนักงานได้ บัญชีทนายที่เพิ่มจากเมนูทีมจะมีโปรไฟล์และบัญชีเข้าสู่ระบบแยก ใช้ชื่อสำนักงานเดียวกับเจ้าของ และไม่ใช้โควต้าคดีแยกจากสำนักงาน เจ้าของสำนักงานเปิดเมนู **ทีมสำนักงาน / มอบหมายคดี** เพื่อเพิ่ม/ระงับบัญชีและมอบหมายคดีของตนให้ทนายที่เปิดใช้งานได้

เจ้าของสำนักงานมองเห็นคดีที่สร้างในบัญชีตนและคดีที่มอบหมายในสำนักงาน สมาชิกทนายมองเห็นคดีที่มีโปรไฟล์ตนเป็นผู้รับผิดชอบตามกลไกสิทธิ์คดีเดิม การระงับสมาชิกจะปิดบัญชีและยกเลิก session ปัจจุบัน โดยไม่ลบข้อมูลหรือการมอบหมาย

บัญชีสมาชิกใหม่ต้องมีชื่อผู้ใช้ รหัสผ่านเริ่มต้นอย่างน้อย 12 ตัวอักษร ชื่อ-นามสกุล และเลขใบอนุญาตทนาย ผู้จัดการสำนักงานต้องส่งรหัสเริ่มต้นให้สมาชิกอย่างปลอดภัย สมาชิกสามารถใช้เมนูจัดการรหัสผ่านของระบบเดิมเพื่อเปลี่ยนรหัสภายหลัง
