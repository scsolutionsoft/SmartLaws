# คู่ความและลูกความในคดี

เปิดคดีผ่านวิซาร์ด 4 ขั้นตอน:

1. ข้อมูลคดี ศาล เลขคดี และฝ่ายที่ทนายรับว่าความ
2. ชื่อคู่ความบนหน้าปก จำนวนคู่ความ (ถ้าทราบ) และรายชื่อบุคคลพร้อมลำดับตามสำนวน
3. เลือกเฉพาะบุคคลที่รับว่าความให้
4. ตรวจสอบ วันนัด ทีมงาน และยืนยันเปิดคดี

ตัวอย่าง: จำเลยทั้งหมด 20 คน เพิ่มรายชื่อจำเลยที่ 2 และ 7 แล้วเลือกทั้งสองคนในขั้นตอน 3 ไม่จำเป็นต้องกรอกอีก 18 คนก่อน บันทึกคดีและคู่ความในธุรกรรมเดียว หักเครดิต 1 คดี ถ้าข้อมูลไม่ผ่านตรวจสอบจะไม่สร้างคดีหรือหักเครดิต

## เพิ่มหรือแก้ไขภายหลัง

เมนูแก้ไขและลบคดี → **คู่ความ / ลูกความ** หรือปุ่ม **จัดการคู่ความ / เพิ่มแก้ไขลูกความ** ในหน้าแก้ไขคดี เพิ่มชื่อ แก้ชื่อ ลำดับ ฝ่าย เลขประชาชนและโทรศัพท์ได้ แล้วเลือกรับว่าความและตรวจสอบก่อนบันทึก ไม่หักเครดิตเพิ่ม ชื่อคู่ความบนหน้าปกยังแก้ผ่านหน้าแก้ไขคดีทั่วไป

ลำดับห้ามซ้ำภายในฝ่ายเดียวกัน และห้ามเกินจำนวนที่ระบุ กรณีข้อมูลเดิมมีลำดับซ้ำจะแสดงรายชื่อเดิม ให้ทนายตรวจและแก้ให้ถูกก่อนบันทึก ไม่จัดลำดับใหม่โดยอัตโนมัติ

ระบบใช้ CaseParties.Id เป็นตัวเชื่อมเอกสาร บัญชีลูกความและการรับว่าความ ของทนายเจ้าของสำนวน ส่วน IsOurClient บอกว่าเป็นลูกความที่ยังรับว่าความ ไม่มีการสร้างสำนวนเพิ่มตามจำนวนลูกความ

การเลิกรับว่าความให้ยกเลิกเครื่องหมาย ไม่ลบแถวคู่ความเก่าหรือข้อมูลประกอบ บัญชีลูกความถูกปิดสิทธิ์เฉพาะคดีนั้นและยังใช้คดีอื่นได้ เมื่อเลือกกลับมาให้ทนายเปิดสิทธิ์บัญชีอีกครั้งตามต้องการ เอกสารที่บันทึกแล้วไม่เปลี่ยนข้อความย้อนหลัง

เลขประชาชนของคู่ความที่ผูกบัญชีแล้วไม่เปลี่ยนผ่านหน้านี้ เพื่อไม่ย้ายสิทธิ์ผิดคน การสร้างบัญชีตรวจเลขให้ตรงข้อมูลลูกความด้วย

PartyVersion ป้องกันการบันทึกทับจากหน้าจอเก่า รายชื่อ/ฝ่ายที่รับว่าความสร้างข้อความ RepresentingPartyOrder สำหรับเอกสารใหม่และปุ่มดึงข้อมูลตนเอง ส่วนปุ่มดึงข้อมูลลูกความให้เลือกบุคคลจริงจากผู้ที่ยังรับว่าความ

คงรูปแบบฐานข้อมูลรายคดีเดิม จึงรวมรายชื่อ ลำดับ การรับว่าความ จำนวนคู่ความ และเวอร์ชันไว้ในการสำรอง/กู้คืนเดิมได้ เอกสารและแชทลูกความยังใช้สิทธิ์รายบุคคลเดิม

ตรวจสอบ: `scripts/CasePartiesIntegration` (API/ฐานข้อมูลจริง), `scripts/case-parties-smoke.mjs` (วิซาร์ดและการแก้ไขบนเดสก์ท็อป/มือถือด้วย API จำลอง)
