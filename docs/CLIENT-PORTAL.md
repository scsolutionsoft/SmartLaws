# บัญชีลูกความและการติดต่อทนาย

## ฝั่งทนาย
เมนู **บัญชีลูกความ / แชท** หรือปุ่มในหน้าแก้ไขคดี → เลือกคดี → เพิ่มชื่อลูกความ (คู่ความที่เป็นลูกความ) → สร้างบัญชี

เฉพาะทนายเจ้าของคดีเป็นผู้สร้าง ระงับ/เปิดบัญชี รีเซ็ตรหัสผ่าน เลือกเอกสารที่ให้ดู และตอบแชทได้ เสมียนกับแอดมินไม่สามารถทำรายการเหล่านี้แทนเจ้าของคดีได้

ชื่อผู้ใช้เป็นเลขประจำตัวประชาชน 13 หลัก หนึ่งบัญชีผูกกับหลายคดีผ่าน SL_ClientIdentities และ SL_ClientCaseLinks การเพิ่มคดีให้เลขเดิมใช้บัญชีและรหัสผ่านเดิม ไม่สร้างบัญชีซ้ำหรือรีเซ็ตรหัสผ่าน เลขที่ใช้ผูกเก็บใน CitizenNumber ซึ่งมี unique index

บัญชีใหม่ใช้เลข 13 หลักเป็นรหัสผ่านเริ่มต้นตามที่ทนายกรอก รหัสผ่านเก็บเป็น hash ส่วนเลขประจำตัวใช้เป็นชื่อผู้ใช้และกุญแจผูกคดี ลูกความต้องตั้งรหัสใหม่อย่างน้อย 10 ตัวอักษรที่ไม่ใช่เลข 13 หลักก่อนดูข้อมูลคดี เมื่อเปลี่ยนหรือรีเซ็ตจะเพิกถอนเซสชันทั้งหมด

## ฝั่งลูกความ
เปิด `/client.html` (หรือใช้ทางเข้าพื้นที่ลูกความบนหน้าล็อกอินเดิม) หน้าแยกโทนม่วงอ่อน/ครีม ออกแบบสำหรับมือถือ มีภาพรวมคดี วันนัดและเอกสาร และแชทกับทนาย บัญชีพนักงานที่เปิดหน้าลูกความจะมีทางกลับพื้นที่ทำงานเดิม

API ลูกความใช้ allowlist `/api/client/*`, `/api/auth/me`, `/api/auth/logout` เท่านั้น ข้อมูลประกอบสำนวนภายใน หมายเหตุในนัด ข้อมูลเลขบัตรของคู่ความ เอกสารส่วนตัวทนาย และ API พนักงานไม่เปิดให้ลูกความ ช่วงก่อนเปลี่ยนรหัสเริ่มต้นอนุญาตเฉพาะข้อมูลบัญชี เปลี่ยนรหัส และออกจากระบบ

## เอกสารและข้อความ
เริ่มต้นไม่แชร์ไฟล์ใดโดยอัตโนมัติ ทนายเลือกเอกสารให้แต่ละบัญชีได้ แม้อยู่ในคดีเดียวกันก็ไม่เห็นเอกสารหรือแชทของบัญชีอื่น ไฟล์จากแชทแชร์ให้คู่สนทนาโดยอัตโนมัติและอยู่ในคลังสำนวน รองรับ PDF/PNG/JPG ไม่เกิน 1 GB ต่อไฟล์ ตรวจชนิดไฟล์ที่เซิร์ฟเวอร์และสตรีมลงดิสก์ส่วนตัว เอกสารสตูดิโอที่ทนายแชร์ส่งออก DOCX ส่วนลิงก์ภายนอกเปิดได้เฉพาะ HTTPS

แชทมีสถานะอ่านแล้ว/ส่งแล้ว ย้อนดูทีละ 100 ข้อความ หน้าลูกความตรวจข้อความใหม่ทุก 10 วินาทีเมื่อเปิดแชทและแท็บยังแสดง ฝั่งทนายมีปุ่มโหลดล่าสุด RequestId ป้องกันการส่งซ้ำเมื่อลองใหม่ ไฟล์ที่อ้างในแชทไม่ลบแยกจากคลังเพื่อรักษาประวัติสนทนา

ZIP สำรองคดีรวมข้อมูลบัญชีที่ผูกคดี สิทธิ์แชร์ ประวัติแชท และไฟล์แนบ แต่ไม่รวมรหัสผ่าน/hash เมื่อยืนยันลบคดี ระบบลบความสัมพันธ์และข้อความเฉพาะคดีนั้น หากยังมีคดีอื่นที่เปิดสิทธิ์จะใช้บัญชีเดิมต่อได้ หากไม่เหลือคดีที่เปิดสิทธิ์จะเพิกถอนเซสชัน การลบทั้งหมดเกิดขึ้นในธุรกรรมเดียวกับข้อมูลคดี เครดิตไม่เปลี่ยน

## ตรวจสอบ
- `dotnet run --project scripts/ClientPortalIntegration/ClientPortalIntegration.csproj`: ฐานข้อมูลจริงด้วย fixture ที่ล้างเมื่อจบ ครอบคลุม owner access, ชื่อซ้ำ, password change, allowlist, แชร์แยกคน, แชท/ไฟล์/ส่งซ้ำ, ระงับ/รีเซ็ต, ZIP และการลบ
- `scripts/client-portal-smoke.mjs` และ `scripts/client-desk-smoke.mjs`: Playwright ใช้ API จำลอง ตรวจ UX ลูกความ/ทนาย การแนบไฟล์ การหนี HTML และหน้าจอมือถือ

## หลายคดีและบัญชีเดิม
ลูกความเลือกคดีจากเมนู คดีของฉัน API /api/client/cases คืนเฉพาะคดีที่มีสิทธิ์ ส่วนข้อมูล ไฟล์ และแชทระบุ ?caseId= เสมอ หากมีหลายคดีและไม่เลือกจะปฏิเสธคำขอ

การระงับสิทธิ์ใช้เฉพาะคดี ไม่ระงับบัญชีรวม ทนายรีเซ็ตรหัสผ่านไม่ได้หากบัญชีนี้มีคดีที่เป็นของทนายอื่นด้วย เพื่อไม่เปลี่ยนข้อมูลเข้าสู่ระบบข้ามเจ้าของคดี

บัญชีเก่าที่ใช้เลขคดีไม่มีเลขประจำตัวที่กู้คืนจาก hash ได้ ทนายเลือก ผูกคดี / ยืนยันเลขประจำตัว เพื่อระบุเลขจริง ระบบเปลี่ยนชื่อบัญชีเดิม หรือรวมประวัติแชทและสิทธิ์ไฟล์เข้าบัญชีเลขนั้นโดยคงรหัสผ่านของบัญชีปลายทาง บัญชีเก่าที่ยังไม่ยืนยันยังเข้าใช้ชื่อเดิมได้
