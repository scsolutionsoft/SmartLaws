# ข่าวประชาสัมพันธ์และการติดต่อ

- เมนูข่าวประชาสัมพันธ์: สมาชิกอ่านข่าวที่อยู่ในช่วงเผยแพร่ ผู้ดูแลเพิ่ม แก้ไข ลบข่าว และตั้งวันเวลาเริ่ม–สิ้นสุดเป็นเวลาไทยได้
- ภาพรองรับ PNG/JPG ไม่เกิน 2 MB และลิงก์ YouTube แบบ watch, youtu.be หรือ shorts ใช้ตัวเล่น youtube-nocookie
- หน้าเข้าสู่ระบบคงสองคอลัมน์เดิม และเพิ่มข่าวด้านล่าง ข่าวที่เผยแพร่เป็นข้อมูลสาธารณะ ไม่ควรใส่รายละเอียดสำนวน
- กล่องข้อความ: สมาชิกติดต่อผู้ดูแลได้ในบทสนทนาของตน ผู้ดูแลเลือกสมาชิกเพื่อเริ่มข้อความหรือตอบกลับ ใช้ปุ่มโหลดข้อความล่าสุดเพื่อรับข้อความใหม่ แสดงล่าสุด 200 ข้อความ
- ปฏิทินนัด → เปิดนัด → กระบวนพิจารณาและคำร้องตามวันนัด: อัปโหลดหลายไฟล์ เชื่อมไฟล์เดิม หรือสร้างแบบคำร้อง (๗) จากสตูดิโอ ต้นฉบับใช้ร่วมกับคลังสารบัญ ไม่ทำสำเนาซ้ำ
- เมนูแก้ไขและลบคดีสำหรับเจ้าของบัญชีทนาย: การลบต้องพิมพ์ยืนยัน ลบข้อมูลประกอบอย่างถาวร ไม่คืนเครดิตและไม่คิดเครดิตเพิ่ม ใช้ข้อจำกัดสิทธิ์เดิมของ API

ระบบสร้างตาราง SL_News และ SL_Messages อัตโนมัติเมื่อเริ่มแอป ไม่มีการเปลี่ยนสูตรเครดิต

ตรวจสอบ: dotnet build SmartLaws.Web.csproj และ dotnet run --project scripts/Integration/Integration.csproj (ต้องเปิดเซิร์ฟเวอร์ที่ localhost:5088 และเชื่อม SQL Server ได้)

## เพิ่มข่าวตัวอย่างเพื่อทดสอบ

เรียกจากโฟลเดอร์โครงการ: `dotnet run --project scripts/SeedCommunity/SeedCommunity.csproj`

เพิ่มข่าวตัวอย่าง 2 รายการพร้อมภาพปกและวิดีโอ COJ Channel เรื่องการไกล่เกลี่ยก่อนฟ้อง เริ่มเผยแพร่ทันที 30 วัน ใช้บัญชีแอดมินที่มีอยู่เป็นเจ้าของรายการ ไม่เปลี่ยนข่าวอื่นหรือเครดิต และเรียกซ้ำจะไม่เพิ่มรายการชื่อเดิมหรือเขียนทับการแก้ไขของแอดมิน ภาพปกมาจาก YouTube ของวิดีโอนั้นและระบุแหล่งที่มาในข่าว
