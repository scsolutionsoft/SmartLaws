# ⚖️ SmartLaws — ระบบบริหารจัดการคดีความ แบบฟอร์มศาลยุติธรรม และลายเซ็นอิเล็กทรอนิกส์

**SmartLaws** คือระบบเว็บแอปพลิเคชันสำหรับทนายความและสำนักงานกฎหมาย เพื่อบริหารจัดการสำนวนคดีความ (ทั้งคดีอาญาและคดีแพ่ง รองรับทั้งบทบาท **ทนายโจทก์** และ **ทนายจำเลย**) พร้อมระบบจัดทำคำฟ้อง คำร้อง คำแถลง คำขอ คำให้การ และแบบพิมพ์ศาลมาตรฐาน **(๑) – (๑๕)** และใบต่อ **(๔๐ ก.)** อัตโนมัติ

## ✨ คุณสมบัติหลัก (Key Features)

1. **สตูดิโอแบบพิมพ์ศาลยุติธรรม A4 (Court Form Studio):**
   - รองรับแบบพิมพ์ศาลมาตรฐานครบชุด `(๑)` ปกหน้าสำนวน, `(๒)` หน้าสำนวน, `(๓)` สารบาญ, `(๔)` คำฟ้อง, `(๕)` คำขอท้ายคำฟ้องแพ่ง, `(๖)` คำขอท้ายคำฟ้องอาญา, `(๗)` คำร้อง/คำแถลง/คำขอ, `(๘)` บัญชีทรัพย์, `(๙)` ใบแต่งทนายความ, `(๑๐)` ใบมอบฉันทะ, `(๑๑)/(๑๑ ก.)` คำให้การจำเลย, `(๑๒)–(๑๔)` หมายเรียก และ `(๑๕)` บัญชีระบุพยาน พร้อมใบต่อ `(๔๐ ก.)` อัตโนมัติ
   - ระบบตัดคำภาษาไทยตามพจนานุกรม (`Intl.Segmenter`) ล็อกกลุ่มตัวเลข จำนวนเงิน และวันเดือนปีไม่ให้ฉีกข้ามบรรทัด
   - รองรับการพิมพ์ออกเป็นเอกสาร **PDF (A4)** ที่แสดงเส้นประบรรทัดครบถ้วนตรงตามหน้าพรีวิว 100% และการส่งออกไฟล์ **Word (`.docx`)**
2. **ระบบลายเซ็นอิเล็กทรอนิกส์ & โหมดเว้นว่างเพื่อเซ็นจริง (E-Signature & Wet Signature):**
   - วาดลายเซ็นบนหน้าจอ หรืออัปโหลดไฟล์ภาพลายเซ็นพร้อมระบบลบพื้นหลังกระดาษสีขาวอัตโนมัติ
   - เลือกสลับโหมดแสดงลายเซ็นอิเล็กทรอนิกส์ หรือเว้นว่างทุกช่องเพื่อให้ผู้เซ็นเซ็นจริงด้วยปากกาบนเอกสารที่สั่งพิมพ์
3. **คลังไฟล์สำนวนคดีตามสารบัญแบบพิมพ์ศาล (Case File Directory):**
   - จัดเก็บไฟล์ PDF, รูปภาพ, ลิงก์ไฟล์ และแบบพิมพ์ศาลแยกตามรหัสสารบัญ `(๑)–(๑๕)` พร้อมแสดงจำนวนไฟล์ จำนวนหน้า สถานะไฟล์ และป๊อบอัพเปิดอ่าน PDF/รูปภาพในระบบ
4. **ระบบแยกแอคเคาท์ทนายความ เสมียนทนาย และระบบบริหารบริการ (Admin & Subscription):**
   - แยกข้อมูลสำนวนคดีตามบัญชีทนายความ (เห็นเฉพาะคดีของตนเอง)
   - ทนายความสามารถเพิ่มและมอบหมาย **เสมียนทนาย** ประจำสำนวนคดีได้ (เสมียน 1 คนสามารถทำงานให้ทนายความได้หลายท่าน)
   - ระบบลงทะเบียนทดลองใช้งานฟรี 3 คดี ระบบแจ้งสลิปโอนเงิน และระบบแอดมินบริหารโควต้าโดยปกปิดความลับสำนวนคดีของทนายความ

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **Backend:** ASP.NET Core (.NET 9.0), Microsoft.Data.SqlClient, DocumentFormat.OpenXml
- **Database:** Microsoft SQL Server (`SmartLaws`)
- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript, Sarabun Legal Typography

## 🚀 การรันโปรเจกต์ (Getting Started)

```bash
dotnet build SmartLaws.Web.csproj
dotnet run --project SmartLaws.Web.csproj --urls "http://localhost:5088"
```
